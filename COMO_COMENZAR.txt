JOSHOS 2.0 · SUITE PERSONAL COMPLETA

ACORDAMOS: NO COMPILAR APK NI EXE TODAVÍA.

Si ya tenés el repositorio joshuadev2007/joshos:
1) Abrí JoshOS 1.0, andá a Configuración y descargá un respaldo JSON.
2) Extraé el ZIP «JoshOS_ACTUALIZACION_2_0.zip».
3) En GitHub, dentro de joshos, seleccioná Add file > Upload files.
4) Arrastrá todos los archivos extraídos a la raíz del repositorio. Conservar games/penales.html, native/prepare.mjs y demás rutas.
5) Tocá Commit changes. ¡Nada de Actions todavía!
6) Probá JoshOS 2.0 desde GitHub Pages.

Las nuevas secciones son Mi Día Perfecto, Metas de Ahorro, De Cero a Mi Meta, Aula Mágica, Reino Rojinegro y Penalty Legends. El resto continúa disponible. No está «Nuestra Historia» (app de pareja).

Cuando vos decidas compilar, GitHub Actions podrá preparar Android APK y Windows EXE. Antes de eso se revisarán los detalles de los instaladores y la preservación de datos.

Los datos se guardan localmente por dispositivo; la migración desde Bitácora y LevelUp requiere JSON. No subas los JSON privados a GitHub público. La bóveda cifra solo sus notas; el resto se almacena localmente sin cifrado.

Para más detalles consultá README.md y GUIA_PARA_ACTUALIZAR.txt.
